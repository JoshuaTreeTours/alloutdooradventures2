# Phase III guide selection policy

Phase III prioritizes remaining U.S. city guides by native Engine6 tour inventory and genuine content defects.

Wikipedia and other source-reference links are neutral and do not count against guide quality. Already rebuilt Phase I/II cities and national-park guides are excluded. The audit separates full rebuild candidates from surgical cleanup candidates and guides that should simply be left alone.

The generated `reports/phase3-engine6-guide-priority.md` and JSON files are report outputs from `scripts/rank-phase3-engine6-guide-priority.ts`; they are not committed by this analysis branch.
